# vocab-quiz-cli

An interactive command-line quiz tool written in Python for testing terms, definitions, and language vocabulary.

## Features
- Shuffles study items each session
- Tracks and displays your final score
- Easy to expand with custom decks and topics

## Run Locally
```bash
git clone https://github.com/muthee44/vocab-quiz-cli.git
cd vocab-quiz-cli
python quiz.py
```
